# Data Model: Bruno Scaffolder

**Phase**: 1 — Design & Contracts
**Date**: 2026-03-06

## Entities

### 1. OpenAPI Specification (Input)

The input contract file parsed by the scaffolder.

| Field                                | Type   | Source | Notes                                                                       |
| ------------------------------------ | ------ | ------ | --------------------------------------------------------------------------- |
| `openapi`                            | string | root   | Version string; must start with `3.`                                        |
| `info.title`                         | string | root   | Used for logging only                                                       |
| `servers[]`                          | array  | root   | Fallback for base URL when config has no match                              |
| `paths`                              | object | root   | Keys are URL path templates; each contains method objects                   |
| `paths.{path}.{method}`              | object | nested | An operation: `tags`, `operationId`, `parameters`, `requestBody`, `summary` |
| `paths.{path}.{method}.tags`         | array  | nested | Primary grouping mechanism → controller folder name                         |
| `paths.{path}.{method}.operationId`  | string | nested | Preferred `.bru` filename source                                            |
| `paths.{path}.{method}.parameters[]` | array  | nested | `in`: path, query, header; `name`, `required`, `schema`                     |
| `paths.{path}.{method}.requestBody`  | object | nested | Contains `content.application/json.schema`                                  |
| `components.schemas`                 | object | root   | Reusable schema definitions resolved via `$ref`                             |

### 2. Scaffolder Configuration

External JSON file at `bruno-scaffolder-config.json`.

| Field                 | Type     | Default                                      | Notes                                |
| --------------------- | -------- | -------------------------------------------- | ------------------------------------ |
| `defaultCompanyName`  | string   | `"Contoso"`                                  | Prefix for collection folder name    |
| `defaultEnvironments` | string[] | `["LOCAL","DEV","TST"]`                      | Environment `.bru` files to generate |
| `defaultBaseUrls`     | object   | `{LOCAL: "https://localhost:5001/api", ...}` | Keyed by environment name            |

### 3. Bruno Collection (Output)

The generated folder structure.

| Artifact          | Path Pattern                                   | Generated By                                                |
| ----------------- | ---------------------------------------------- | ----------------------------------------------------------- |
| Collection config | `{CompanyName} - {ApiName}/bruno.json`         | `New-BrunoCollectionFile` (JSON config) + inline JSON block |
| Environment file  | `{collection}/environments/{ENV}.bru`          | `New-BrunoEnvironment`                                      |
| Controller folder | `{collection}/{ControllerName}/`               | `New-Item -ItemType Directory`                              |
| Folder metadata   | `{collection}/{ControllerName}/folder.bru`     | `New-BrunoFolderFile`                                       |
| Request file      | `{collection}/{ControllerName}/{FileName}.bru` | `New-BrunoApiFile`                                          |

### 4. Environment File

A `.bru` file under `environments/`.

| Section       | Content          | Notes                                                       |
| ------------- | ---------------- | ----------------------------------------------------------- |
| `vars`        | `baseUrl: {url}` | One variable per line                                       |
| `vars:secret` | `[]` (empty)     | Placeholder for user secrets; never populated by scaffolder |

### 5. Request File (.bru)

A `.bru` file representing one API endpoint.

| Section            | Present When                    | Content                                    |
| ------------------ | ------------------------------- | ------------------------------------------ |
| `meta`             | Always                          | `name`, `type: http`, `seq: 1`             |
| `{method}`         | Always                          | `url`, `body: json\|none`, `auth: inherit` |
| `params:query`     | Query params exist              | `~name: {{PLACEHOLDER}}` (~ = optional)    |
| `headers`          | Header params exist             | `name: {{PLACEHOLDER}}`                    |
| `body:json`        | POST/PUT/PATCH with requestBody | JSON template from schema                  |
| `vars:pre-request` | Path params exist               | `name: {{PLACEHOLDER}}`                    |
| `settings`         | Always                          | `encodeUrl: true`, `timeout: 0`            |

## Schema Resolution Flow

```text
requestBody.content["application/json"].schema
  │
  ├── has $ref? ──→ resolve from components.schemas (track visited set)
  │                    │
  │                    └── resolved schema ──→ re-enter this flow
  │
  ├── type: object ──→ iterate properties, recurse each
  │
  ├── type: array ──→ recurse items schema, wrap result in [ ]
  │
  ├── allOf ──→ merge properties from all sub-schemas
  │
  ├── oneOf/anyOf ──→ use first sub-schema (pragmatic choice)
  │
  ├── type: string ──→ "{{PLACEHOLDER}}"
  ├── type: integer ──→ 0
  ├── type: number ──→ 0.0
  ├── type: boolean ──→ false
  │
  └── circular $ref detected ──→ "{{CIRCULAR_REF}}"
```

## Request Body Type Coverage

| Body Shape                   | OpenAPI Schema                                     | Expected `.bru` body:json Output                                        |
| ---------------------------- | -------------------------------------------------- | ----------------------------------------------------------------------- |
| Simple object                | `type: object, properties: {name: {type: string}}` | `{"name": "{{PLACEHOLDER}}"}`                                           |
| Nested object                | Property has `$ref` to another object schema       | Recursively expanded: `{"address": {"street": "{{PLACEHOLDER}}", ...}}` |
| Array of objects             | `type: array, items: {$ref: "#/..."}`              | `[{"field": "{{PLACEHOLDER}}"}]`                                        |
| Array of primitives          | `type: array, items: {type: string}`               | `["{{PLACEHOLDER}}"]`                                                   |
| `allOf` composition          | `allOf: [{$ref: A}, {properties: {extra: ...}}]`   | Merged properties from A + extra                                        |
| Top-level array as root body | Schema root is `type: array`                       | Entire body wrapped in `[]`                                             |
| No schema / empty body       | No `requestBody` or no `content`                   | `body: none` (no body:json section)                                     |

## Filename Derivation

```text
Endpoint (method, path, operationId, tags)
  │
  ├── operationId present? ──→ Get-SanitizedName(operationId)
  │
  ├── path has API-name pattern? ──→ extract (e.g., /Get-Something-Name/)
  │
  └── fallback ──→ "{Method}-{PathSegments}" or "{Method}-{Resource}-By{Param}"

Post-derivation:
  └── Check for duplicates within controller folder
        └── If collision ──→ prepend HTTP method to both colliding names
```

## State Transitions

This tool is stateless per invocation. No persistent state is maintained between runs. On regeneration:

- Existing files at the target path are overwritten
- New files are created
- Files not in the current swagger are left untouched (safe for manual additions)
